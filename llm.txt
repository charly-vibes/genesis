# genesis-vibes

Shared crate for cross-cutting CLI/AIX/self-healing infrastructure in the charly-vibes suite.

## Modules

| Module | Description |
|--------|-------------|
| `envelope` | structured CLI output envelope |
| `suggestions` | self-healing error suggestions |
| `managed_block` | managed block injector |
| `aix` | AIX artifact generation |
| `config` | shared config management |
| `guide` | CLI scaffold (Verbosity, CliVerbosity, OutputFormat, CliFormat, Output, ErrorSink, GuideBuilder, Guide). Format auto-detect: JSON for non-TTY stdout, Human for terminals. |
| `fixture` | test scratch environments |
| `feedback` | agent issue reporting |
| `suite_linter` | suite-wide lint checks |
| `doctor` | diagnostics with auto-fix |
| `cli` | CLI helpers |
| `status` | cross-tool status dashboard |
| `scaffold` | init scaffolding |
| `discovery` | tool discovery via .genesis/tools.toml manifest |

## Key Commands

| Command | Purpose |
|---------|---------|
| `(use via genesis)` | All modules are library APIs, not CLI subcommands |
